
ASHEN — A dark fantasy boss-fighting game built with Godot 4  made of entirely ASCII characters.

### `A dark fantasy world, rendered in ASCII.`

`

**ASHEN** is a dark fantasy boss-fighting game built around an unusual visual idea: an entire world brought to life through ASCII-style graphics.

Instead of relying on conventional pixel art or realistic textures, ASHEN uses text-inspired visuals, atmospheric effects, and shaders to create its own identity. The result is a world that feels stripped down, mysterious, and hostile — where even a simple character on the screen can feel like something out of a nightmare.

Built with **Godot 4**, ASHEN combines ASCII-inspired visuals with challenging boss encounters, dark environments, and music designed to give each fight its own atmosphere.

## `> THE WORLD`

The world of ASHEN isn't a friendly place.

Three major encounters stand between you and the end. Each boss brings a different challenge, and each level pushes you further into a world consumed by darkness.

### `01 // THE HOLLOW WARDEN`

Your first encounter.

An introduction to the world of ASHEN and the dangers hiding within it. Survive the fight, learn the rhythm of combat, and prepare for what comes next.

### `02 // THE DROWNED SOVEREIGN`

The second trial.

The journey gets harder, and surviving your first encounter won't be enough to guarantee victory here.

### `03 // ASHFANG, THE EMBER DRAGON`

The final encounter.

The last major challenge in your journey through ASHEN. Everything leads to this fight.

## `> WHAT MAKES ASHEN DIFFERENT?`

- **ASCII-inspired visuals** — a text-driven aesthetic that gives the game its distinct identity.
- **Shader-based effects** — visual techniques that help transform the game world into something atmospheric and unusual.
- **Three major boss fights** — the Hollow Warden, the Drowned Sovereign, and Ashfang, the Ember Dragon.
- **A dark fantasy atmosphere** — a world built around danger, mystery, and decay.
- **Dedicated music for encounters** — different tracks for the main menu and boss battles.
- **Built from the ground up in Godot 4** — using GDScript, scenes, and custom shaders.

## `> RUN THE GAME`

Want to explore the world yourself or take a look at the code?

1. Install **Godot 4**.
2. Clone or download this repository.
3. Open Godot and select **Import**.
4. Navigate to the ASHEN project folder and select `project.godot`.
5. Open the project and press **F6** to run the current scene, or **F5** to run the main project.

Make sure you open the actual project folder containing `project.godot`, rather than an individual script or scene file.
